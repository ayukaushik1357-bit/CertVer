# CertVer 🛡️

CertVer is a decentralized, blockchain-backed certificate verification system that helps prevent credential fraud and enables instant certificate validation.

## ✨ Features

* 🔐 Tamper-proof certificate verification
* ⚡ Instant validation using Certificate ID or hash
* ⛓️ Blockchain-backed records using Aptos
* 🌐 Decentralized certificate verification

## 🛠️ Tech Stack

* **Frontend:** Next.js, React, TypeScript
* **Styling:** Tailwind CSS
* **Blockchain:** Aptos
* **Smart Contracts:** Move

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/ayukaushik1357-bit/CertVer.git
cd CertVer
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
