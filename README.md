# CertVer 🛡️

CertVer is a decentralized, blockchain-backed certificate verification system designed to eliminate credential fraud and provide instant, tamper-proof validation for academic and professional achievements.

---

## Features
- **Tamper-Proof Verification:** Records certificate issuance and status on the blockchain to prevent forgery.
- **Instant Validation:** Allows employers and institutions to verify credentials instantly using unique certificate IDs or cryptographic hashes.
- **Decentralized Trust:** Removes single points of failure and reliance on centralized certificate authorities.
- **Modern Tech Stack:** Built with a robust full-stack architecture leveraging Next.js, TypeScript, and smart contract integration (Aptos).

---

## Tech Stack
- **Frontend / Framework:** Next.js (React), TypeScript, Tailwind CSS
- **Blockchain / Web3:** Aptos integration for secure ledger management
